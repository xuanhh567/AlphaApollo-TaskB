# Phase 5 Plan: Prompt 自动生成

**Phase:** 5
**Status:** Planned
**Language:** 中文
**Goal:** 从 registry 中的 `SkillSpec` 自动生成 prompt 工具说明，让新增 / 移除 skill 时 prompt 不需要手写工具 schema 和 examples。

## Requirements Covered

- PROMPT-01: 工具说明必须能从 registry 中的 `name`、`description`、schema 和 examples 自动生成。
- PROMPT-02: 新增或移除 skill 后，prompt 工具说明应自动更新，不需要手写每个工具说明。
- PROMPT-03: prompt 必须明确告诉模型使用统一 `<tool_call>` 格式。

## Locked Decisions From Context

- Prompt 优先教新 `<tool_call>{...}</tool_call>` 格式。
- 旧 `<python_code>` / `<local_rag>` 兼容留在 env bridge，不作为新 prompt 的主要格式。
- answer 仍然使用 `<answer>...</answer>`。
- 本阶段只接 `informal_math_training` prompt。
- 不改 reward、rollout、env 执行链路。

## Beginner Mental Model

Phase 5 要解决的是：

```text
以前：prompt 手写“你可以用 python_code/local_rag”
现在：prompt 从 SKILL.md 自动读出“有哪些工具、怎么传参、例子是什么”
```

也就是：

```text
SKILL.md
-> loader
-> SkillSpec
-> registry
-> prompt renderer
-> 模型看到的工具说明
```

## Wave 1: Prompt Renderer

### Task 1.1: 新增 `prompt.py`

**文件：**

```text
alphaapollo/core/skills/prompt.py
```

**建议函数：**

```python
render_skill_prompt_block(specs: list[SkillSpec]) -> str
```

**输出内容包含：**

- skill name
- description
- parameters
- required / optional / default
- examples
- 统一 `<tool_call>` JSON 格式

### Task 1.2: 参数 schema 渲染

把 `SkillParameter` 渲染成模型容易看懂的文本，例如：

```text
- code (string, required): Python code to execute.
- top_k (integer, optional, default=3): Number of retrieved chunks per query.
```

### Task 1.3: examples 渲染

把 `SkillExample.arguments` 渲染成：

```xml
<tool_call>{"name":"python_code","arguments":{"code":"print(1 + 1)"}}</tool_call>
```

## Wave 2: Prompt 模板接入

### Task 2.1: 简化 training prompt 模板

**文件：**

```text
alphaapollo/core/environments/prompts/informal_math_training.py
```

当前有多个手写模板：

```text
NO_TOOL
NO_HIS
WITH_HIS
RAG_NO_HIS
RAG_WITH_HIS
RAG_ONLY_NO_HIS
RAG_ONLY_WITH_HIS
```

Phase 5 建议改为：

```text
基础 prompt + 可选 history + 自动生成工具说明 + answer 说明
```

### Task 2.2: 保留 no-tool 行为

如果没有启用 skill，或者 `max_steps == 1`：

```text
只提示模型推理并输出 <answer>...</answer>
```

### Task 2.3: 接入 enabled skill

`get_policy_training_prompt(...)` 可以接收：

```python
tool_specs: list[SkillSpec] | None
```

如果 `tool_specs` 存在，就用它自动生成说明。

为了兼容旧调用，也可以暂时保留 `tool_config`，但内部把它转换成 skill 列表。

## Wave 4: 测试

### Task 4.1: renderer 单测

**文件：**

```text
tests/test_skill_prompt_renderer.py
```

**测试用例：**

### Task 4.2: training prompt 单测

可以在同一个测试里验证：

3. 没有工具时，不出现 `<tool_call>`。
4. history prompt 仍然包含 `{memory_context}` 和 `{step_count}` 占位。
